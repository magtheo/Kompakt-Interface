## Task 5 — section triage (scratchpad + inbox docs)

**Parser** (`domain/Notes.kt`, pure + unit-tested):
- `data class NoteSection(heading, title, body, startLine, endLine)` — split on `^## ` lines;
  preamble (before first `## `) is NOT a section; title = text after ` — ` when present, else
  the full heading text; body = lines after the heading, verbatim.
- `removeNoteSection(text, section)` — exact-expectation string surgery; collapses the blank
  lines the section occupied so no doubled gaps remain; preamble untouched.

**VM** (`NoteEditorViewModel` gains triage; deps += taskRepository, organizationRepository):
- `sections` in UiState, derived on load/reload (scratchpad `## ts — title` + inbox docs).
- Actions, all checksum-guarded against the LOADED checksum, all followed by reload:
  - `newNoteIn(section, target)` — `createNote(NoteDraft(text = body.ifBlank { title },
    projectId = target?.id))` FIRST (external effect), then PUT source minus section.
    Crash-between ⇒ duplicate — safe direction, documented. Triage-filed notes carry NO
    source_type (server set is {chat, agent_run, capture, triage}; EntityKind has no match —
    provenance = file location + git history; deliberate, not an omission).
  - `appendTo(section, target: Note)` — GET target fresh (text+checksum), PUT target with
    the section appended verbatim (heading + body) FIRST, then PUT source minus section.
    Same duplicate-safe ordering.
  - `createTaskFrom(section)` — `TaskDraft(title = section.title, sourceType = NOTE,
    sourceId = noteId)`; section is NOT consumed (create = derive, not move — agent-flow parity).
  - `discard(section)` — single PUT minus section. One tap; git history is the undo.
  - Keep = collapse row (no action).
- Targets: `saveTargets` = vault projects only (T-022e filter — machine projects 422);
  `appendTargets` = observeNotes() minus self minus scratchpad.
- 409 on any PUT ⇒ conflict notice + reload (fresh checksum adopted on next action attempt).

**UI** (`NoteEditorScreen` read view): when `role ∈ {scratchpad, inbox}` and sections exist,
render section cards (title + body preview, `▸` expand) instead of raw markdown; expanded row
shows the actions; pickers are expandable inline ListRows (T-022c convention, no dialogs).
Role `note` / no sections ⇒ unchanged markdown read view.
